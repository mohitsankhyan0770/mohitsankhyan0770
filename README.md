## 🤖 Agentic AI System

<div align="center">

### Multi-Agent LLM · Local AI · Tool Calling

</div>

An autonomous AI system designed around **local LLMs and multiple specialized agents**. The system explores how an AI application can break down tasks, use tools, maintain context and evaluate its own output.

**Tech:** `Python` · `LLMs` · `Ollama` · `ChromaDB`

### What it does

* 🧩 **Multi-agent architecture** for specialized tasks
* 🧠 **Planning and reasoning** for task execution
* 🔧 **Tool calling** for interacting with external functionality
* 💾 **Persistent memory** using ChromaDB
* 🔍 **Self-critic module** for evaluating generated responses
* 🏠 **Local LLM execution** using Ollama
